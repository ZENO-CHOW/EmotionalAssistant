# 项目三：大学生情绪管理智能搭档
Emotional Management Smart Assistant
## 项目简介：

面对大学生情绪问题高发与心理服务资源不足的严峻现实，本项目致力于推动人工智能与循证心理治疗的深度融合，构建具有理论创新与技术突破的智能化情绪干预平台。项目以辩证行为治疗（Dialectical Behavior Therapy, DBT）为核心技能框架，深度融合多模态情感大模型技术，通过整合文本、语音、面部表情等多维度数据，构建针对中国大学生群体的细致度情绪识别模型，实现动态情绪波动建模。在此基础上，核心突破在于开发基于强化学习的自适应DBT-AI模型，实现深层赋能：通过开发具备高共情能力的AI智能体（Agent），能像经验丰富的治疗师一样，根据用户实时反馈，自适应调整训练难度与策略；还可模拟DBT技能训练搭档，进行个性化、情景化的交互练习。本项目旨在最终形成“识别-干预-反馈”的智能闭环系统，并在多所高校开展实证研究，验证其有效性、安全性与可推广性。成果将为高校与医疗机构提供一套标准化、可扩展的数字疗法平台，为我国心理健康服务体系数字化转型升级提供可复制的技术样板与实践范式。

## DBT核心技能智能化训练系统开发

围绕 DBT 的四大核心技能模块（情绪调节、痛苦耐受、人际效能和正念），本研究将开发一个具备智能交互和自适应特性的 **DBT智能化训练系统**，实现从静态技能学习到动态情境化、个体化应用的升级。系统可以帮助大学生在真实压力情境中快速调用技能，从而提升情绪稳定性、减少冲动行为并改善人际功能。

研究任务主要包括：

### 1) DBT 四大模块技能的数字化和结构化处理：
将技能拆解为可测量、可算法化的多维度训练单元，建立跨技能模块的逻辑关系（如正念 → 痛苦耐受 → 情绪调节 → 人际效能），实现技能内容的标准化，使算法能够识别、匹配并推荐适宜的训练路径。

### 2) 构建智能体进行交互训练：
构建包含多场景模拟、可交互的DBT智能练习搭档（AI Partner），可模拟DBT团体中的搭档角色，与用户进行技能扮演练习，可模拟考试压力、人际冲突、宿舍矛盾、恋爱困扰等大学生常见场景，以及提出合理请求、拒绝他人、有效沟通等人际互动练习，根据用户输入即时调整引导逻辑、提供即时反馈，使技能训练更贴近大学生的真实体验。

### 3) 自适应干预引擎开发：
根据用户的情绪模式、技能掌握度评估和行为数据，构建个性化 DBT 学习推荐算法和自适应智能推送，当用户出现明显情绪波动、反复熬夜、社交退缩等风险行为时，系统可自动推送“危机技能包”（如TIPP、STOP技巧），并通过对话提供分步骤行为指导和支持，解决传统 DBT 中用户“紧急时刻”想不起来用技能、“不会选技能”的痛点。

### 4) 智能化效果评估与闭环自我检测系统：
在训练前后实时评估用户的情绪-行为状态变化，形成“评估—训练—反馈—再评估”的闭环机制。

### 5) 行为设计提高技能依从性：
引入行为科学策略，包括积分、徽章、连续训练奖励等奖赏机制、设定微目标、强化循环、情景提醒等，促使大学生能长期坚持技能训练，使技能真正泛化到真实生活中。

- **竞品分析**：有时候会分析一下市面上同类竞品的情况，有时候是对比同一需求以前的解决方案，总之核心是要体现你当前产品做的价值。

- **角色与权限**：列出所有用户类型（如：管理员、老师、学生），以及如果涉及到不同端也要写。

- **业务流程图 —— 最重要！**
    工具推荐:Mermaid(直接写在Markdown里)或ProcessOn。
    要求:必须画出"泳道图"，清晰展示用户操作->系统判断->数据库读写->界面反馈的全过程。

- **功能详细说明**：
  - **输入**：用户能点哪里？填什么？
  - **处理逻辑**：系统怎么算？（比如：抑郁评分>10分，系统自动触发预警，这个逻辑必须写死）。
  - **输出**：界面弹什么窗？跳什么页？

- **其他**：数据埋点与非功能需求：（对于医疗项目，强调数据隐私和响应速度）。

- **AI 核心能力定义**
  - **模型人设与系统提示词**
    - 教学点：不要在 PRD 里写“要像个医生”。
    - 要写：“角色是拥有10年经验的三甲医院心内科主治医师。语言风格专业、冷静、富有同理心，严禁使用网络流行语。回答必须基于《内科学》第九版。”
  - **上下文与知识库**
    - 痛点：AI 只有通用知识，没有私有知识。
    - PRD 要求：必须明确 AI “能看什么书”。
    - 例子（AISP项目）：“AI 扮演病人时，其回答必须严格基于后台上传的‘病例剧本（JSON）’，严禁编造剧本以外的症状。”—— 这就是对 RAG（检索增强生成）的需求定义。
  - **输入/输出约束**
    - 输入限制：用户能发图片吗？语音最长多少秒？。
    - 输出格式：AI 输出的是纯文本，还是结构化的 JSON？
    - 例子（情绪管理项目）：“Agent 对用户的干预建议，必须包含：1. 情绪识别结果；2. 共情话术；3. DBT 技能推荐。且总字数不超过 300 字。”
  - **边界控制与安全兜底**
    - 拒答机制：“当用户询问具体用药剂量时，AI 必须拒绝回答，并话术引导：‘我是 AI 助手，具体用药请遵医嘱。’”
    - 敏感词过滤:涉及自杀、暴力倾向的关键词触发什么流程?(如:直接转人工/报警逻辑)。
  - **评测标准 —— 怎么算“做好了”？**
    - **准确性**：比如“AISP的症状描述准确率需 > 95%”。
    - **响应速度**：“语音对话延迟 < 2秒”。
    - **一致性**：“同一个问题问三次，回答的核心逻辑不能变。”

# 什么是DBT技能训练：

1. DBT技能训练可以被看作是一门**“情绪与生活管理”的实操课程**。

2. 针对对象为存在心理问题的来访者

3. 技能训练分为四个模块：

    1. 正念

    2. 痛苦承受

    3. 情绪调节技巧

    4. 人际效能

4. 这四个技能模块，并非单纯的线性递增关系，而是互相关联、可以组合使用，能闭环的技能系统。

5. 尽管如此，模块间也存在一定难度等级（但并非严格线性）：正念\-\>痛苦承受\-\>情绪调节\-\>人际效能

6. 从基础到应用、从生存到发展、从自身到关系



# 将DBT训练过程拆分为识别、干预、反馈三个环节：

# **第一环节：识别 **

这是闭环的**起点和评估基础**，目标是精确“定位”问题所在，而非泛泛而谈。

- **核心工作**：进行**行为链分析** 和**解决方案分析**。

- **具体操作**：

    1. **数据收集**：以来访者的**日记卡**为核心工具，识别具体的问题行为（如自伤、暴食、激烈争吵）、伴随的**情绪、想法、身体感觉和事件诱因**。

    2. **链式解析**：与来访者一起，像慢镜头回放一样，细致地回顾问题行为发生前**每一环**（诱发事件 \-\> 解读 \-\> 情绪升级 \-\> 无效应对行为），找到最关键的“薄弱环节”或“技能缺失点”。

    3. **辩证评估**：评估是**情绪调节**、**痛苦承受**、**人际效能**还是**正念**技能的缺失？是动机问题、理解问题，还是环境阻碍？

- **专业视角**：识别环节拒绝模糊的“情绪不好”，而是聚焦**具体情境下的具体行为序列**，为精准干预提供“靶点”。

# **第二环节：干预 **

基于识别环节的“靶点”，应用特定的DBT技能进行教学和演练。

- **核心工作**：**技能匹配**与**针对性演练**。

- **具体操作**：

    1. **技能匹配**：根据识别出的“薄弱环节”，从四大模块中选取**最直接相关的技能**。例如：

        - 识别出“情绪剧烈升级时无法忍受” \-\> 匹配**痛苦承受技巧**（如TIP技能：用冷水改变生理状态）。

        - 识别出“不敢拒绝他人导致怨恨累积” \-\> 匹配**人际效能技巧**（如DEAR MAN公式）。

    2. **现场教学与演练**：在技能训练小组或个体治疗中：

        - **讲授**：清晰解释技能的原理和步骤。

        - **示范**：治疗师进行示范。

        - **角色扮演**：让来访者在安全环境中演练，治疗师给予实时指导。

        - **布置家庭作业**：制定非常具体的计划，让来访者在实际生活中尝试应用。

- **专业视角**：干预不是泛泛地“教技能”，而是**“为解决你上周二晚上发生的那个具体问题，我们现在来学习和演练这个专门针对它的技能”**。

# **第三环节：反馈 **

这是闭环中确保干预有效、并驱动下一轮识别与调整的**关键验证和校准步骤**。

- **核心工作**：**验证效果**与**调整策略**。

- **具体操作**：

    1. **回顾家庭作业**：在下次会面中，首要任务是回顾技能应用作业。**“你尝试用那个技能了吗？具体发生了什么？”**

    2. **分析结果**：

        - **如果成功**：强化成功经验，探讨如何泛化到其他情境。

        - **如果未尝试或失败**：这不视为“治疗失败”，而是**新一轮“识别”环节的开始**。治疗师会带着好奇心与来访者一起分析：“是什么阻碍了技能的使用？”（例如：是忘记了？觉得没用？尝试了但更糟？）这产生了新的、更精确的“识别”信息。

    3. **调整与闭环**：

        - 根据反馈，治疗师可能需要**调整干预策略**（如将技能分解得更简单、处理使用技能的心理障碍）。

        - 这个反馈结果**直接输入到下一个“识别”环节**，开启新一轮的“识别\-干预\-反馈”循环。

- **专业视角**：反馈环节体现了DBT的**科学家\-实践者**模型。每一次干预都是一个“单案实验”，其效果通过数据（行为报告）验证，并据此不断假设、检验和修正治疗方法。

# **闭环系统的价值与专业精髓 **

这个 **“识别（靶点）\-\> 干预（打靶）\-\> 反馈（校验）”** 的闭环，正是DBT区别于普通支持性谈话治疗的核心：

1. **数据驱动，而非主观臆断**：整个循环建立在行为日记和具体事件分析的基础上，杜绝模糊。

2. **主动解决问题，而非被动倾听**：治疗师是积极的教练，而非被动的听众。

3. **赋能来访者**：来访者通过这个闭环，最终学会自己成为“自己的行为分析师和治疗师”，掌握自我管理的终身工具。

4. **确保治疗忠诚度**：这个结构化的闭环防止治疗偏离轨道，始终聚焦于行为改变。

因此，一名专业的DBT训练师，本质上是一位**熟练的闭环系统导航员**，他/她引导来访者在“识别\-干预\-反馈”的螺旋中不断上升，最终从情绪和行为的混乱走向清晰、有效和可控的生活。
