# 情绪图片选择系统设计（IAPS/GAPED）

## 📖 背景介绍

### IAPS（International Affective Picture System）
- **来源**: 国际标准情感图片库
- **维度**: 效价（Valence）、唤醒度（Arousal）、支配度（Dominance）
- **评分**: 1-9分制
- **用途**: 通过图片选择辅助判断用户情绪状态

### GAPED（Geneva Affective Picture Database）
- **来源**: 日内瓦情感图片库
- **特点**: 包含更多负面情绪图片
- **用途**: 补充IAPS，提供更丰富的情绪识别

---

## 🎯 系统目标

1. **隐性评估**: 通过图片选择而非直接提问，降低用户防御心理
2. **辅助判断**: 结合用户选择的图片特征，辅助AI判断情绪类型
3. **情绪强度**: 配合滑块组件，准确评估情绪强度
4. **数据积累**: 收集用户选择数据，优化情绪识别模型

---

## 🔄 工作流程

### 用户端流程
```
1. 用户进入对话/日记记录
   ↓
2. 系统展示情绪图片（6-12张）
   ↓
3. 用户选择最符合自己感受的图片（可多选）
   ↓
4. 用户拖动滑块标记情绪强度（1-10）
   ↓
5. 提交到后端分析
   ↓
6. 后端返回情绪识别结果
   ↓
7. AI根据结果进行个性化对话
```

### 后端分析逻辑（供参考）
```
1. 接收用户选择的图片ID列表
   ↓
2. 查询图片的VAD值（效价、唤醒度、支配度）
   ↓
3. 计算平均VAD值
   ↓
4. 根据VAD映射到情绪类型
   - 低效价 + 高唤醒度 → 焦虑/愤怒
   - 低效价 + 低唤醒度 → 悲伤/抑郁
   - 高效价 + 高唤醒度 → 兴奋/快乐
   - 高效价 + 低唤醒度 → 平静/放松
   ↓
5. 结合用户标记的强度
   ↓
6. 输出情绪识别结果 + 置信度
```

## 🧩 组件设计

### 1. EmotionImageSelector.vue（主组件）

**Props**:
```javascript
{
  mode: 'chat' | 'diary',      // 使用场景
  imageCount: 8,                // 显示图片数量
  minSelection: 1,              // 最少选择数量
  maxSelection: 3,              // 最多选择数量
  showIntensity: true           // 是否显示强度滑块
}
```

**Methods**:
```javascript
{
  loadImages(),                 // 加载图片
  handleImageSelect(imageId),   // 处理图片选择
  handleIntensityChange(value), // 处理强度变化
  submitSelection()             // 提交选择结果
}
```

**Emits**:
```javascript
{
  'selection-complete': { images, intensity, emotionResult }
}
```

---

### 2. ImageGallery.vue（图片画廊）

**功能**:
- 展示图片网格
- 支持多选/单选
- 选中状态高亮
- 加载动画

**交互**:
- 点击图片 → 边框高亮 + 勾选标记
- 超过最大选择数 → 提示"最多选择3张"
- 选择后记录选择时长（用于分析）

---

### 3. EmotionIntensitySlider.vue（强度滑块）

**Props**:
```javascript
{
  min: 1,
  max: 10,
  step: 1,
  defaultValue: 5,
  labels: ['轻微', '中等', '强烈', '非常强烈']
}
```

**UI特性**:
- 拖动时实时反馈
- 数字显示 + 文字描述
- 渐变色背景（绿→黄→橙→红）
- 震动反馈（移动端）

---

### 4. EmotionResult.vue（结果展示）

**UI效果**:
- 淡入动画
